1Overview

CloudDevis lets Algerian artisans and companies create legally-compliant commercial documents (quotes, invoices, delivery notes) in minutes — with automatic TVA, Timbre Fiscal, and NIF/RC/NIS/AI validation. The same Next.js codebase serves the marketing site, the web dashboard/editor, an admin back-office, and the mobile app (a Capacitor wrapper around the /mobile route).

Who uses it

Artisan (self-employed, simplified, 11-digit NIF) and Entreprise (full fiscal IDs, RIB/CCP). Persona is chosen at signup and drives what UI shows.

Surfaces

Landing · Auth · Dashboard (editor, documents, clients, reports, team, subscription, partner) · Admin (dark theme) · Mobile app.

Status

Web mature. Mobile functional but ships behind a browser-preview wrapper (see §15). BL (bon de livraison) recently added end-to-end.

5Architecture & routing

Next.js App Router. Server components by default; auth pages, dashboard layout, editor and mobile are client components. Mutations always go through /api/* routes (no Server Actions) so every write gets Sentry wrapping + explicit validation.

Route groups

GroupGuardNotes
Public (/, /auth/*, /legal/*, /download, /enterprise, /help)noneLogin/register also run useGuestOnly → bounce authed users to /dashboard.
/dashboard/*layout.tsx → /api/auth/meWraps OfflineSyncProvider + TrialGate.
/admin/*separate admin sessionDark theme (admin.css), withAdminAuth on APIs.
/mobileMobileShell self-authCapacitor target — but it's a preview wrapper (see §15).

i18n

localePrefix:'never' — no /fr URL segment; locale comes from the NEXT_LOCALE cookie / Accept-Language and is applied in the root layout (<html dir> flips to rtl for Arabic). API responses are localized via src/lib/api-i18n.ts.

6Authentication

Stateless JWT (HS256 via jose) stored in an httpOnly cookie, backed by a Session row keyed by jti so tokens are revocable (logout deletes the row; every check re-verifies the row exists). The JWT payload carries userId, email, name, mode, sector, country, language, subscriptionStatus, jti.

Flows

  • Email/password → /api/auth/login (rate-limit + CSRF + bcrypt) → createSession() → cookie.
  • OAuth (Google/GitHub) → /api/auth/oauth/[provider] → callback links/creates an Account+User. New users are routed to /auth/welcome to pick Artisan/Entreprise, which PUT /api/user/profile {mode} and re-issues the cookie.
  • Guest guard — useGuestOnly() sends already-authed visitors away from login/register.
NoteAdmin auth is separate — its own ADMIN_JWT_SECRET, cookie, and withAdminAuth middleware. Never mix the two.

Key files: src/lib/auth.ts, src/lib/adminAuth.ts, src/app/api/auth/**, src/app/auth/welcome/page.tsx, src/hooks/useGuestOnly.ts.

9Algerian business logic (the compliance core)

src/lib/dgi.ts is the single source of truth for tax + identity; calculations.ts wraps it; validation.ts adds localized messages.

TVA

Legal rates [0, 9, 19]. Per-item rates supported and weighted after discount.

Timbre Fiscal

1000 DA, applies when TTC ≥ 10 000 (Art. 220 CII). Exempt: DEVIS, ATTACHEMENT, BL, and cheque/virement payments.

Identity

NIF 11 (individual) vs 15 (company) — isIndividualNIF/isCompanyNIF; RC 9–14 alnum; NIS/AI 10 digits.

Tafqit

Amount-in-words in FR & AR for the legal "arrêté à la somme de…" line.

Numbering

PREFIX-YYYY-NNNNN — DEV/FAC/PRO/BC/BR/BL/INT/ATT.

BL special case

calculateDocument zeroes TVA/timbre/TTC for bl so every renderer hides tax rows.

Runtime exposure is gated by ENABLED_DOC_TYPES = ['devis','facture','bl'] (src/lib/config.ts) — the other types exist in code but aren't shown in the UI.

10Document & PDF pipeline

Web editor

src/app/dashboard/editor/page.tsx + useEditorState / useEditorActions / useEditorUndo. A section registry (src/components/editor/sections/*) renders per-type sections driven by DOC_TYPE_SECTIONS / DOC_TYPE_DEFAULT_FIELDS; users tune visibility in the CustomizationModal. Drafts autosave to localStorage; live right-pane preview with 4 style templates (Haussmann/Nordic/Velours/Industrielle).

GotchaThere are two PDF paths. Web download builds HTML via src/lib/generateDocumentHTML.ts → print window. Mobile (and any server render) uses packages/pdf-engine (@react-pdf, type-aware devis-fr.tsx, Arabic template-ar.tsx). Keep both in sync when changing a doc type.

11Mobile app

A Capacitor wrapper. MobileShell hosts bottom-tab screens (Home, Documents, Company, Clients, Settings, Create). State lives in zustand stores persisted through Capacitor Preferences / localStorage; offline sync via useApiSync + offline.ts + SQLite, replaying a queue on reconnect.

FlashFacture (create/edit)

A single-canvas pattern (src/mobile/components/create/*): LivePaper renders the live invoice; tapping a zone morphs the persistent CreateDock (add item / client / details) with no navigation. Totals count up. Persona-aware: artisans see fewer doc types (BC/BR/BL behind "+ Plus") and a simplified company form.

Libs: pdf.ts (engine bridge), whatsapp.ts/share.ts (native → Web Share → download fallback), toast.ts (native → DOM pill), network.ts.

12Subscription & gating

src/lib/subscription.ts: TRIAL_DAYS = 7, canCreateDocument(), per-plan doc/team/storage limits. TrialGate shows a countdown for trials and a paywall for EXPIRED. Plans in pricing.ts (free / standard / enterprise). Checkout via LemonSqueezy (cards, webhook-driven) or Wise (manual DZD transfer).

13Security & compliance

  • Field encryption — AES-256-GCM for NIF/RC/NIS/AI/IBAN in the companyInfo JSON (fieldCrypto.ts).
  • Sessions — httpOnly JWT + DB jti revocation; bcrypt (10) + 12-char password policy.
  • CSRF on state-changing routes; rate limiting (Upstash / in-memory) on login & admin login.
  • CSP configured in next.config.ts (frame-ancestors none, object-src none).
  • DGI compliance baked into validation & calculations (§9).

14Deployment

Web (Vercel)

vercel.json runs build:prod → prisma migrate deploy then build. So a schema change is only live once its migration is committed and a deploy runs. Env vars set in the Vercel dashboard. DB is Neon (use the direct URL for migrations, pooler for runtime).

Mobile (Capacitor / Android)

npm run mobile:sync then build/sign in Android Studio (keystore clouddevis-release.jks). Users download the APK from /download (button + scan QR → Google Drive link). Drop a hosted APK at public/clouddevis.apk for a first-party download.

Read §15The Capacitor server.url currently points at /mobile — a production anti-pattern with real UX fallout. Fix before the next release.

15🔴 Known issues & technical debt

The honest state of things — start here when planning the next sprint.

P0 · CriticalCapacitor server.url = /mobile ships the browser-preview wrapper.

The APK loads src/app/mobile/page.tsx, which renders MobileShell inside a fake 390×844 "iPhone 14 Pro" frame with Plein écran / Réinitialiser dev controls. On a real phone the app is boxed and clipped → the "non-scroll", "non-responsive", and stray-buttons bugs in the QA report are this wrapper, not the app. Capacitor's own guidance is that server.url is not for production (blank-screen / plugin-injection risks). Fix: a clean route (e.g. /app) that renders <MobileShell/> full-bleed, point server.url there — or, better, bundle webDir for true offline. Then rebuild the APK.

Refs: ionic-team/capacitor discussions #5075, #4080, #1478.

P0 · Mobile UX safeguards
  • No unsaved-changes guard on create — switching tabs risks losing the in-progress doc.
  • A document can be saved with no client → shows "Client inconnu" in lists. Client should be required.
  • No document status workflow — everything saves as DRAFT (no sent/paid transitions).
  • Mobile client form lacks an email field; the "Clients: 0" stat isn't a CTA.
P1 · Data migrations mid-flight LineItem and Company models exist but Document.items:Json and User.companyInfo:Json are still the live source; migrateDocumentItems() / migrateUserCompany() are partial. Finish, backfill, then drop the JSON columns.

Other flagged items

  • Recurring invoices — model + API exist, but there's no scheduler/cron to actually emit them.
  • Offline sync — queue replays last-write; no conflict resolution strategy.
  • Tests thin — unit (calculations/dgi/validation) + api (auth/clients/documents/teams); e2e minimal.
  • BL tax-hiding relies on per-renderer guards; attachement signature templates partial.
  • generateDocumentHTML.ts carries unrelated uncommitted work; the BL enum migration must be deployed to prod before BL is used (else POST /api/documents 500s).
  • .github/workflows/schema-drift.yml is uncommitted (push token lacked workflow scope).

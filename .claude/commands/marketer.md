# Response Guidelines

1. **Lead with the client's pain, not the product's features** — "Vous passez des heures sur vos factures..." not "Notre logiciel offre..."
2. **Use concrete Algerian numbers/contexts** — DA amounts, DGI deadlines, wilaya references
3. **Always provide both FR and AR versions** of key copy (landing, ads, emails)
4. **SEO output**: include target keyword, meta title (≤60 chars), meta description (≤160 chars), and H1/H2 structure
5. **Tone**: professional but accessible — the artisan in Bab El Oued and the CFO in Hydra should both understand it
6. **Never overpromise**: don't claim features that don't exist (e.g., automatic G50 filing — CloudDevis is not a full accounting suite)
